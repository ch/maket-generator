# Mockup Generator (Maket Generator)

Інтерактивний веб-додаток для створення та експорту реалістичних студійних мокапів сцен з Instagram-постами (iPhone + 4 парящі картки з динамічними тінями).

## ✨ Особливості

- **Чистий SVG Вектор (Pure Vector Engine)**:
  - Телефон (iPhone з Dynamic Island, status bar, рамкою) та картки намальовані у чистому SVG.
  - Нативні SVG тексти (`<text>`) без втрати чіткості при будь-якому масштабуванні.
  - Векторні іконки Instagram UI (heart, comment, share, bookmark, nav).
- **Студійні тіні 360° (Крутилка «Сонечко» ☀️)**:
  - Обертання джерела світла на 360° навколо сцени.
  - Фізичний розрахунок вектора відкидання тіні (тригонометричні зміщення $dx$, $dy$).
  - Повзунки висоти підйому (Distance), розмиття (Blur radius) та інтенсивності тіні.
  - Можливість увімкнення/вимкнення тіней (ВКЛ / ВИКЛ).
- **Масштабування зі збереженням пропорцій**:
  - Масштабування віджетів зі 100% збереженням геометрії.
  - Авто-масштабування сцени на весь екран (Auto-Fit to 100% viewport).
- **Гнучке налаштування холста**:
  - Пресети пропорцій: 1:1, 4:5, 5:4, 16:9, 9:16, Еталон (16:11).
  - Введення точних розмірів у пікселях (Ширина px та Висота px).
  - Швидкі пресети роздільної здатності (1080×1080, 1080×1350, 1080×1920, 1920×1080, 2560×1440, 3840×2160).
  - Налаштування фону (кольори, студійні градієнти, довільний color picker).
- **Система пресетів**:
  - Збереження у браузері (`localStorage`) із зазначенням назви.
  - Клонування/дублювання пресетів.
  - Імпорт та експорт у файли `.json` (зберігаються лише конфігурації без важких фотографій).
- **Експорт надвисокої чіткості**:
  - Векторний `.svg` файл без втрати якості (для Figma / Illustrator).
  - `.png` та `.jpeg` з роздільною здатністю 1x, 2x, 4x UHD (до 6400 × 4400 px).
  - Копіювання зображення в буфер обміну в один клік.

## 🚀 Запуск проекту

```bash
# Встановлення залежностей
npm install

# Запуск dev сервера
npm run dev

# Збірка проекту для production
npm run build
```
